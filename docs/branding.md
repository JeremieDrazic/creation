# Brand identity

## Current choices

Creation is the display name and a tribute to the Creator. Use lowercase creation for technical identifiers.

The current expressive typeface is **Cormorant Garamond Light 300**, chosen for its closeness to the lettering in the approved visual studies. Use its plain **C** as the provisional sign. Keep the full name where recognition requires it. No flourish, letter cuts, botanical emblem or animated symbol is selected.

Retained font and license: [Cormorant Garamond](../moodboard/branding/typeface-study/fonts/cormorant.ttf), [OFL](../moodboard/branding/typeface-study/fonts/cormorant-OFL.txt). Source: [official Google Fonts files](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), retrieved October 8, 2026.

## Implementation review

- Validate actual sizes, optical spacing, French accents, English text and readability against both experience backgrounds.
- Choose the supporting UI typeface separately; it is still open.
- Sample the actual selected font/metrics for Fireflies word targets so typography and particles share one silhouette.
- Keep any future custom logo lettering separate from ordinary site typography.

## Deferred

A definitive logo and loader visual/motion design are deferred. Rejected emblem and wordmark studies are not production references. A new identity proposal should be judged statically with the chosen typography before adding motion.

Motion should have a clear phrasing and soft settling, with authored overlapping groups and varied durations where useful. Equal repeated delays alone produced a mechanical stagger and were rejected. Randomness is not a substitute for composition; naming an easing function does not establish perceived elegance.
