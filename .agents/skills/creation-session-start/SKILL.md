# Start a Creation session

Read repository AGENTS.md, apps/docs/session-state.md and the bounded-session protocol in
apps/docs/collaboration.md. Resolve paths from the Creation repository root.

Verify the branch and working tree before treating the handoff as current. Read the brief, decisions
and task-specific references required by AGENTS.md. Give a short French briefing with implemented
work, exploratory code, pending owner review, verification limits and the proposed session
objective. Discuss the first production file's responsibilities before writing experience code.

Check the dependency-review checkpoint in session-state.md. When due, propose a dedicated
maintenance session rather than silently replacing the planned feature session. An ordinary start
does not authorize dependency upgrades, publication or a new chat. Follow existing publication
permissions.
