# Working brand reference

Use Cormorant Garamond Light 300 and its plain C as the provisional Creation sign.
[Branding requirements](../../apps/docs/branding.md) are authoritative. Definitive logo and loader
design are deferred.

- [Actual font file](typeface-study/fonts/cormorant.ttf)
- [OFL license](typeface-study/fonts/cormorant-OFL.txt)
- [Official source](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), retrieved
  October 8, 2026.

This font file preserves the input used in the reviewed specimens; production subsetting/formats and
typography sizes are still to validate. Rejected logo studies, motion sketches and other candidate
fonts are not retained as active references.
