# Cormorant Garamond — static intro study

Browser-loadable copy of the retained font in moodboard/branding/typeface-study/fonts/cormorant.ttf,
unchanged. Family: Cormorant Garamond, variable weight 300–700; the approved study uses Light 300.
The original source is Google Fonts, retrieved October 8, 2026; see apps/docs/branding.md.

OFL.txt is the accompanying SIL Open Font License. This TTF is a temporary study delivery file;
production font optimization and shared font ownership remain to be decided after visual review. It
is imported by the intro UI in Storybook and on the application home route.
